# 作业：React 课程展示页

## 目标

使用 React 开发一个基础的“前端学习中心”课程展示页，练习组件拆分、props、列表渲染、状态、事件处理、响应式布局和基础可访问性。

完成作业前请阅读：

- `materials/01-react-and-jsx.md`
- `materials/02-state-and-events.md`
- `materials/03-responsive-and-accessible-ui.md`

## 要求

1. 在 `work/<你的用户UUID>/b7b13773-dc68-49f0-bf78-cc213a30eea5/` 中创建可独立运行的 React 项目，推荐使用 Vite。用户 UUID 以 `learn2ai-context context` 返回的信息为准。
2. 页面包含页头、介绍区域、课程列表和页脚，并至少展示 6 门前端课程。每门课程需包含名称、简介、难度和学习时长。
3. 至少拆分出 `Header`、`CourseList`、`CourseCard`、`SearchBox` 和 `Footer` 组件；课程卡片通过 props 接收数据，并由数组使用 `map` 渲染。
4. 实现课程搜索：输入关键词后，按课程名称或简介实时筛选；匹配时显示结果数量，无匹配时显示明确的空状态。
5. 提供“清空搜索”按钮。按钮在关键词为空时禁用，点击后清空关键词并恢复完整课程列表。
6. 使用 CSS 完成清晰的视觉层级和响应式布局。在约 375px 宽的手机视图中为单列，在 1280px 桌面视图中为多列，且不得出现横向滚动、文字遮挡或控件重叠。
7. 使用语义化 HTML；输入框有可见标签；所有交互可通过键盘完成；交互控件有清晰的 `:focus-visible` 样式。
8. 不要求接入后端或路由。课程数据保存在本地 JavaScript 文件中，不依赖外部 API。
9. 在项目目录添加 `README.md`，写明安装与启动命令、组件划分，以及自己完成的一项设计或技术决策。

## 验证步骤

提交前逐项验证并在 `README.md` 中记录结果：

1. 运行 `npm install`、`npm run build` 和项目已有的 `npm run lint`，记录命令是否通过。
2. 分别搜索一个有结果和一个无结果的关键词，确认结果数量、课程卡片和空状态正确。
3. 点击“清空搜索”，确认输入框清空、完整列表恢复，且空关键词时按钮为禁用状态。
4. 在约 375px 和 1280px 两种视口下检查页面布局。
5. 仅使用键盘 Tab、Shift+Tab、Enter 或 Space 完成搜索框与按钮操作，确认焦点始终可见。

- 功能完整性：页面结构、课程信息、搜索、计数、空状态和清空功能均可用。
- React 实践：组件职责清晰，正确使用 props、状态和列表 `key`，没有直接修改状态。
- 界面质量：视觉层级清晰，在手机与桌面端均可用，无明显布局问题。
- 可访问性：语义结构、标签、键盘操作和焦点样式符合要求。
- 工程质量：目录清楚，构建和检查通过，README 记录真实、完整。
